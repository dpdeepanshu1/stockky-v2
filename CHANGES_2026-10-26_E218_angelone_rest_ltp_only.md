# E218 - market-data /quotes/bulk: an AngelOne row with no live price is no longer published as a fresh live tick

**Why:** `_get_quotes_bulk_core` (the shared price source for the automatic entry path, via real-trade `get_quotes`) read an AngelOne REST row's price as the first positive of `ltp`, `close`, `open`. When `ltp` was 0 (a stock that has not traded yet, a suspended name, a pre-open row) the PREVIOUS close (or the day's open) became the price, the row was tagged `angelone_rest`, stamped `fetched_at = now` and cached for 12 s. Every caller's quote-age check (real-trade Gate 2b `ENTRY_MAX_QUOTE_AGE_S`) therefore treated a yesterday-close price as a 0-second-old live tick, and a BUY limit and stop / target levels could be built on it. The group 244 pre-open stage ("what AngelOne could not price is answered with the last close, with its real age") never saw those symbols because this stage had already "priced" them.
**Change:** new `_angelone_live_price(fq)` returns `ltp` only (None when missing, 0, negative, NaN or not a number); the stage skips such a row, so the symbol continues to the later stages (Dhan, last-close row with its true age, cooldown / leftover cached rows, yfinance). `close` is still used for `previous_close` / `day_change_pct`. `QUOTE_BULK_ANGELONE_CLOSE_FALLBACK=1` restores the old fallback.
**Reverses an E188 test:** `test_zero_ltp_falls_back_to_close_and_shows_no_move` pinned the old fallback on purpose. It is replaced by two tests (default: no row; switch on: the old row). If you want the old behaviour back, set the switch; no code change needed.
**Review:** `_get_quotes_bulk_core` (market-data-service/main.py, 3876-4424) is now read line by line (cache, closed-market, Dhan, live feeds, AngelOne REST, pre-open, cooldown and leftover gates, yfinance). Nothing else needed a fix. Noted, not changed: the yfinance daily-bar row (`yahoo_bulk`) is stamped fetched_at = now although its last bar can be older; that is the last-resort provider and callers already treat it as such.
**Tests:** `python3 -m py_compile` on main.py and both test files; `_angelone_live_price` executed in isolation (ltp, zero, missing, negative, NaN, text, None, switch on). pytest and the full `main` import NOT run (pytest / fastapi not installed here): `pytest tests/test_e218_angelone_rest_ltp_only.py tests/test_e188_bulk_quote_freshness.py tests/test_group244_preopen_bulk_last_close.py tests/test_group487_bulk_small_leftover.py` in market-data-service. Restart market-data-service after deploying.
