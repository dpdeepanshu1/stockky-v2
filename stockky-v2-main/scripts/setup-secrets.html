🔑 Stockky Real Trade — Secrets Setup (2 of 3)

This page generates SESSION_SECRET and DHAN_CREDENTIAL_ENC_KEY only — entirely in your browser, using crypto.getRandomValues(). Nothing here is sent over the network; open your browser's dev tools → Network tab if you want to verify that yourself (there will be zero requests).

ADMIN_PASSWORD_HASH is NOT generated here — it needs to come from the same Argon2 library that verifies it later. Run python3 services/real-trade-service/scripts/generate_secrets.py locally for that one (it can generate all three at once if you prefer a single step).

Save this page locally and open it as a file (not hosted anywhere) if you want to be extra careful — but as shipped, it makes no network calls regardless of how it's opened.
SESSION_SECRET — signs admin login sessions
DHAN_CREDENTIAL_ENC_KEY — Fernet key encrypting your stored Dhan token
Next steps
1. Copy both values above into Render → real-trade-service → Environment.
2. Run the local script for ADMIN_PASSWORD_HASH (see warning above) and add that too.
3. Set ADMIN_USERNAME if you don't want the default admin.
4. Redeploy the service — it refuses to boot until all three are set (see config.py: startup_config_errors()).
5. Close this browser tab when done. Nothing here persists after reload.
